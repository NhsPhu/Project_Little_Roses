# 🌹 Little Roses Foundation

A website project for **Little Roses Foundation**, designed to present the organization's identity and provide an accessible online experience for visitors.

## 📖 About The Project

**Little Roses Foundation** is a web development project focused on building a visually appealing and user-friendly website.

The project aims to create a welcoming digital presence through a structured layout, visual elements, and responsive frontend design.

## 🛠️ Technologies

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layouts, and visual presentation.
- **JavaScript** – Client-side interactions and dynamic behaviors.

## 📂 Project Structure

```text
Project_Little_Roses/
│
├── css/             # Stylesheets
├── images/          # Images and visual assets
├── js/              # JavaScript files
└── index.html       # Main entry point
```

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/NhsPhu/Project_Little_Roses.git
```

### 2. Navigate to the project directory

```bash
cd Project_Little_Roses
```

### 3. Run the project

Open `index.html` directly in your browser.

For a better development experience, you can use the **Live Server** extension in Visual Studio Code.

## 💻 Development

You can modify the project by editing:

- `index.html` – Main website structure.
- `css/` – Website styles and responsive layouts.
- `js/` – Interactive functionality.
- `images/` – Website images and assets.
